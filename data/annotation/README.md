# Anotación TerMacroMetro

Esta carpeta contiene los lotes de anotación manual utilizados para construir
el modelo de sentimiento macroeconómico boliviano.

## Etiquetas permitidas

- positivo
- neutral
- negativo

## Valores de duda

- 0: clasificación clara
- 1: requiere revisión

## Reglas

La anotación debe seguir:

docs/ANNOTATION_GUIDE.md

No modificar las columnas estructurales de los lotes.
Solo completar:

- sentimiento
- anotador
- fecha_anotacion
- duda
- comentario
